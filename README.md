# Sales & Customer Analytics Dashboard

## Project Goal
Analyze retail sales data to find which products, regions, and customers drive profit, and which cause losses.

## Business Questions
1. Which category and sub-category earn the most profit?
2. Which region is the weakest, and why?
3. Do high discounts reduce profit?
4. Who are the top 10 customers?
5. How do sales and profit change by month and year?

## Dataset
Superstore Dataset on Kaggle, originally from Tableau sample data. 9,994 order lines, 2014 to 2017.

The raw file is not included in this repo. Download it from Kaggle and place it in `data/raw/`.

## Tools
Python (Pandas), PostgreSQL, Power BI, Git/GitHub
